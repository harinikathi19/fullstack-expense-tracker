# Full-Stack Expense Tracker with Budget Management

A modern full-stack expense tracking application with authentication and real-time analytics.

## Features

- User authentication (secure login & registration)
- Add, edit, and delete expenses
- Budget management system
- Real-time analytics dashboard
- Responsive UI

## Tech Stack

Frontend: React  
Backend: Node.js, Express  
Database: PostgreSQL  

## Installation

1. Clone the repository
git clone https://github.com/harinikathi19/fullstack-expense-tracker

2. Navigate to project folder
cd fullstack-expense-tracker

3. Install dependencies
npm install

4. Start the development server
npm run dev

## Usage

- Register or login
- Add your expenses
- Set budgets
- Track spending with analytics
